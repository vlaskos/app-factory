# Golden-path reference apps

Hand-built reference implementations of the supported archetypes — the **target output** of the
`scaffold` + `build` + `test-author` skills. Built "backwards" (by hand, first) to de-risk the golden
path before wiring the autonomous pipeline, and to give the generating skills a worked example per
archetype.

All three conform to the constitution in `../skills/architecture.md`: MVVM + `@Observable` +
Repository + swift-testing, projects generated by XcodeGen (no checked-in `.xcodeproj`).

## Status (verified 2026-10-28 · Xcode 26.2 / Swift 6.2.3)

| Archetype | What it stresses | iOS 26 typecheck | Gating suite |
|-----------|------------------|:---:|:---:|
| [`shopping-list`](shopping-list/) | SwiftData CRUD, list ordering | ✅ | ✅ 7 tests |
| [`bill-splitter`](bill-splitter/) | Decimal/currency, pure `BalanceCalculator` (integer cents) | ✅ | ✅ 14 tests |
| [`calculator`](calculator/) | pure algorithm, precedence, error state, `UserDefaults` | ✅ | ✅ 13 tests |

**34 tests, all green.** Each app has zero external dependencies, so both checks run **fully offline
without XcodeGen**: (a) `swiftc -typecheck` of all `Sources/` against the iphonesimulator SDK, and
(b) a throwaway macOS SwiftPM package mirroring the non-SwiftUI logic + the test files, run with `swift test`.

## Bugs the de-risk caught (would have broken the demo)
- `SortDescriptor(\.isDone)` won't compile — `Bool` isn't `Comparable` and the `NSObject` overload
  doesn't apply to a SwiftData `@Model`. (shopping-list)
- Test `ModelContainer` returned from a factory local deallocates → `save()` SIGTRAPs; hold it as a
  `@Test` struct property. (shopping-list → applied everywhere since)
- Test files using `Decimal`/`IndexSet` must `import Foundation` explicitly (not transitively). (bill-splitter)

Both SwiftData gotchas are banked in `../skills/architecture.md` → § Verified gotchas.
