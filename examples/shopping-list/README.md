# Shopping List — golden-path reference app

Hand-built reference implementing the `shopping-list` archetype to the ESDLC constitution
(MVVM + `@Observable` + SwiftData + Repository + swift-testing). This is the **target output**
of the `scaffold` + `build` skills — built by hand first to de-risk the golden path
(step 1 of "build backwards").

## Stack
- iOS 17 min, Swift 6, SwiftUI, Observation, SwiftData, swift-testing
- **MVVM:** `ItemListModel` (`@Observable @MainActor`) over an `ItemStore` repository — no SwiftData types in the views
- Project generated by **XcodeGen** (`project.yml`) — no checked-in `.xcodeproj`

## Layout
```
project.yml                     ← XcodeGen spec (scaffold-owned)
Sources/App/                    ← @main + composition root (scaffold-owned)
Sources/Shared/                 ← Item @Model, ItemStore repo, DesignTokens (scaffold-owned)
Sources/Features/ItemList/      ← the feature (build-owned)
Tests/ShoppingListTests/        ← swift-testing, AC-tagged (test-author-owned)
```

## Build & test (run locally — needs Xcode + XcodeGen)
```sh
brew install xcodegen            # once
cd examples/shopping-list
xcodegen generate                # project.yml → ShoppingList.xcodeproj
open ShoppingList.xcodeproj      # ⌘R run · ⌘U test
# or headless:
xcodebuild -scheme ShoppingList -destination 'platform=iOS Simulator,name=iPhone 16' build
xcodebuild -scheme ShoppingList -destination 'platform=iOS Simulator,name=iPhone 16' test
```

## Acceptance criteria → tests
| AC | Statement | Covered by |
|----|-----------|-----------|
| AC-1 | adding a non-empty item persists; blank rejected | `ItemStoreTests.addPersists/blankRejected`, `ItemListModelTests.addShows/blankAddErrors` |

## Verification (run 2026-10-28, Xcode 26.2 / Swift 6.2.3)
Built by hand as the backwards-build de-risk. No `.xcodeproj` yet (XcodeGen not installed — needs `brew`),
but the app has **zero external dependencies**, so both checks ran fully offline:

- ✅ **Whole-app typecheck** against the **iOS 26 simulator SDK** under Swift 6 strict concurrency
  (`swiftc -sdk iphonesimulator26.2 -target arm64-apple-ios26.0-simulator -swift-version 6 -typecheck Sources/**`) — GREEN.
- ✅ **Gating suite** — 7 tests / 2 suites via **swift-testing**, in-memory SwiftData, parallel — all PASS.

### Two real bugs caught by actually compiling/running (not eyeballing)
1. **`SortDescriptor(\.isDone)` won't compile.** `Bool` isn't `Comparable`, and `SortDescriptor`'s `Bool`
   overload needs `NSObject` — which a SwiftData `@Model` isn't. Fix: fetch sorted by `createdAt`, then
   partition unchecked-first in Swift (see `ItemStore.all()`).
2. **Test container lifetime → SIGTRAP.** A `makeStore()` factory that returns a store wrapping
   `container.mainContext` lets the local `container` deallocate on return; the next `save()` hits a
   torn-down store and crashes (signal 5). Fix: hold `ModelContainer` as a **stored property** of the
   test struct (swift-testing news a fresh instance per test → per-test isolation *and* retention).
   The app itself is unaffected: its container is owned by `.modelContainer(for:)` at the App scene.

### Still needs a machine with XcodeGen (one `brew install`)
`xcodegen generate` → simulator build/run → signing → TestFlight. Confirm after a build that
`ITSAppUsesNonExemptEncryption=false` lands in the built `Info.plist` (set via the XcodeGen `info:` block).
